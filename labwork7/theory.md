## 0. Основа

### Блок кода `{ }`

Фигурные скобки объединяют несколько команд в **блок**. Условие или цикл управляют всем блоком целиком:

```php
if ($age >= 18) {
    echo "можно";      // обе строки выполнятся,
    echo "проходите";  // только если условие истинно
}
```

### Условие — это выражение, которое даёт `true` или `false`

В скобках у `if`, `while`, `for` стоит **условие**. PHP вычисляет его и смотрит на результат: `true` — выполнить блок, `false` — пропустить.

Обычно условие строится из операторов сравнения:

| Оператор             | Значение                                           |
| -------------------- | -------------------------------------------------- |
| `==`                 | равно (с приведением типов)                        |
| `===`                | равно и того же типа (строго)                      |
| `!=`                 | не равно                                           |
| `<`, `>`, `<=`, `>=` | меньше, больше, меньше или равно, больше или равно |

И логических операторов (подробно были в ЛР3):

| Оператор | Значение                             |
| -------- | ------------------------------------ |
| `&&`     | И — оба условия истинны              |
| `\|\|`   | ИЛИ — хотя бы одно истинно           |
| `!`      | НЕ — переворачивает `true` ↔ `false` |

### Итерация

Один проход тела цикла называется **итерацией**. «Цикл выполнил 5 итераций» = тело цикла выполнилось 5 раз.

## Задание 1 — что выведется и почему

### # 1 — цикл, который не выполнился ни разу

```php
for ($i = 6; $i < 4; $i++) {
    echo "Ё ма со, ё ма хо";
}
echo "i = $i";
```

Сначала устройство `for`. В скобках три части через `;`:

```php
for (НАЧАЛО; УСЛОВИЕ; ШАГ) { ТЕЛО }
```

1. **НАЧАЛО** (`$i = 6`) выполняется **один раз**, до всего остального.
2. **УСЛОВИЕ** (`$i < 4`) проверяется **перед каждой** итерацией. Если `false` — цикл заканчивается.
3. **ТЕЛО** выполняется, если условие истинно.
4. **ШАГ** (`$i++`) выполняется **после** каждой итерации, затем снова проверка условия.

Что происходит здесь:

1. `$i = 6`.
2. Проверка `6 < 4` → `false`. Цикл заканчивается сразу.
3. Тело не выполнилось ни разу, шаг `$i++` — тоже.

Переменная `$i` после цикла **продолжает существовать** и равна 6. Результат: **`i = 6`**.

Вывод: `for` проверяет условие **до** первой итерации. Если условие сразу ложно, тело не выполнится ни разу.

### # 2 — `break`, который так и не сработал

```php
$i = 2;
while ($i < 10) {
    echo ++$i;
    if ($i == 6) {
        break;
    }
    $i++;
}
echo $i;
```

`while (УСЛОВИЕ) { ТЕЛО }` — «пока условие истинно, выполняй тело». Условие проверяется перед каждой итерацией.

`break` — немедленно выйти из цикла.

`++$i` — префиксный инкремент: сначала увеличить, потом вернуть новое значение (ЛР3, задание 3).

За одну итерацию `$i` увеличивается **дважды**: один раз в `echo ++$i`, второй раз в `$i++` в конце.

| Итерация | Проверка `$i < 10` | `echo ++$i` печатает | `$i == 6`? | после `$i++` |
| -------- | ------------------ | -------------------- | ---------- | ------------ |
| 1        | 2 < 10 ✓           | **3**                | нет        | 4            |
| 2        | 4 < 10 ✓           | **5**                | нет        | 6            |
| 3        | 6 < 10 ✓           | **7**                | нет        | 8            |
| 4        | 8 < 10 ✓           | **9**                | нет        | 10           |
| —        | 10 < 10 ✗          | цикл закончен        |            |              |

После цикла `echo $i` печатает **10**.

Результат: **`357910`**.

Ловушка задачи: `$i` действительно становится равным 6 (в конце 2-й итерации). Но проверка `$i == 6` стоит **раньше**, сразу после `echo ++$i`, а в этот момент `$i` всегда нечётное: 3, 5, 7, 9. Поэтому `break` не срабатывает ни разу.

### # 3 — накопление суммы

```php
$a = 2;
for ($b = 0; $b < 5; $b++) {
    $a += $b;
}
echo $a . ", " . $b;
```

`$a += $b` — составное присваивание: `$a = $a + $b` (ЛР3, задание 4).

| `$b` | `$a` до | `$a += $b` | `$a` после |
|---|---|---|---|
| 0 | 2 | 2 + 0 | 2 |
| 1 | 2 | 2 + 1 | 3 |
| 2 | 3 | 3 + 2 | 5 |
| 3 | 5 | 5 + 3 | 8 |
| 4 | 8 | 8 + 4 | **12** |

Дальше шаг делает `$b = 5`, проверка `5 < 5` → `false`, цикл заканчивается.

Результат: **`12, 5`**. `$b` равна 5, а не 4: цикл заканчивается именно потому, что `$b` дошла до 5.

### # 4.1 — бесконечный цикл

```php
$i = 1;
while ($i <= 5) {
    echo $i;
}
```

Внутри цикла `$i` **никак не меняется**. Условие `1 <= 5` истинно всегда, цикл никогда не закончится и будет печатать `1111111…`. Страница бы «зависла» — браузер ждал бы бесконечно, пока PHP не прервёт скрипт по лимиту времени (обычно 30 секунд, настройка `max_execution_time`).

Поэтому в лабе к этому коду добавлен аварийный счётчик `$guard`: через 10 итераций он делает `break`.

Вывод: в теле цикла **обязательно** должно что-то менять условие, иначе цикл не закончится. Чтобы исправить этот код, достаточно добавить `$i++;` в тело.

### # 4.2 — `do-while` выполнится хотя бы раз

```php
$i = 1;
do {
    echo $i++;
} while ($i < -1);
```

`do { ТЕЛО } while (УСЛОВИЕ);` — отличие от `while` в том, что условие проверяется **после** тела. Значит, тело выполнится **минимум один раз**, даже если условие ложно с самого начала.

1. Тело: `echo $i++` — постфиксный инкремент: печатает **старое** значение 1, потом `$i` становится 2.
2. Проверка `2 < -1` → `false`. Цикл заканчивается.

Результат: **`1`**.

Сравнение трёх циклов:

| Цикл | Когда проверяется условие | Минимум итераций |
|---|---|---|
| `for` | перед каждой итерацией | 0 |
| `while` | перед каждой итерацией | 0 |
| `do-while` | после каждой итерации | **1** |

## Задание 2 — можно ли садиться за руль

### `if` / `elseif` / `else`

```php
if (условие1) {
    // выполнится, если условие1 истинно
} elseif (условие2) {
    // если условие1 ложно, а условие2 истинно
} else {
    // если все условия выше ложны
}
```

Условия проверяются **по очереди сверху вниз**. Как только одно оказалось истинным, выполняется его блок, а всё остальное **пропускается**. Выполнится ровно один блок.

### Решение

```php
function canDrive(int $age, bool $hasLicense, bool $isDrunk): string
{
    if ($age < 18) {
        return "нельзя: возраст меньше 18";
    } elseif (!$hasLicense) {
        return "нельзя: нет водительских прав";
    } elseif ($isDrunk) {
        return "нельзя: водитель пьян";
    } else {
        return "можно садиться за руль";
    }
}
```

Логика — проверяем все причины **отказа** по одной:

1. Младше 18 → нельзя.
2. `!$hasLicense` — «НЕ есть права», то есть прав нет → нельзя.
3. Пьян → нельзя.
4. Если ни одна причина не сработала → можно.

Можно было бы проверить всё одним условием:

```php
if ($age >= 18 && $hasLicense && !$isDrunk) { ... }
```

Это тоже правильно, но тогда при отказе непонятно **почему**. Цепочка `elseif` позволяет назвать конкретную причину.

Решение оформлено функцией, чтобы проверить несколько людей, не копируя условия. Типы параметров (`int`, `bool`) и возвращаемый тип `: string` подсказывают, что передавать и что вернётся.

## Задание 3 — время суток

```php
$hour = rand(0, 23);

if ($hour < 0 || $hour > 23) {
    $timeOfDay = "некорректный час";
} elseif ($hour >= 4 && $hour <= 11) {
    $timeOfDay = "утро";
} elseif ($hour >= 12 && $hour <= 16) {
    $timeOfDay = "день";
} elseif ($hour >= 17 && $hour <= 22) {
    $timeOfDay = "вечер";
} else {
    $timeOfDay = "ночь";
}
```

**Попадание в диапазон** записывается двумя сравнениями через «И»: `$hour >= 4 && $hour <= 11` — «час не меньше 4 **и** не больше 11». В математике это `4 ≤ hour ≤ 11`, но в PHP так `4 <= $hour <= 11` писать **нельзя** — нужно два отдельных сравнения.

**Ночь** — это `else`: всё, что не утро, не день и не вечер, то есть 23, 0, 1, 2, 3. Прописывать ночные часы отдельно не нужно — сюда попадает всё оставшееся.

**Первая проверка** — защита от неверных данных: часа 25 или −3 не бывает. Без неё такие значения ушли бы в `else` и считались бы «ночью».

## Задание 4 — числа от 1 до 30 с исключениями и остановками

Здесь две новые команды для управления циклом:

- **`continue`** — пропустить остаток текущей итерации и сразу перейти к следующей. Цикл продолжается.
- **`break`** — полностью выйти из цикла. Цикл заканчивается.

Поэтому:

- «вывести всё, **кроме** …» → `continue`;
- «выводить, **пока** не …» → `break`.

### Оператор `%` — остаток от деления

- `$i % 4 == 0` — остаток от деления на 4 равен нулю, значит число **делится на 4** нацело (кратно 4);
- `$i % 2 != 0` — остаток от деления на 2 не ноль, значит число **нечётное**.

### Кроме кратных 4

```php
for ($i = 1; $i <= 30; $i++) {
    if ($i % 4 == 0) {
        continue;
    }
    echo $i, " ";
}
```

На числах 4, 8, 12… срабатывает `continue`, и `echo` для них не выполняется. Для остальных `if` ложен, и число печатается.

### Кроме нечётных

То же самое с условием `$i % 2 != 0`. Остаются только чётные: 2, 4, 6…

### Кроме чисел, цифры которых в сумме дают 5

```php
$digitSum = intdiv($i, 10) + $i % 10;
```

Для чисел до 99 сумма цифр = десятки + единицы:

- `intdiv($i, 10)` — целочисленное деление на 10, это **десятки**: `intdiv(14, 10)` = 1;
- `$i % 10` — остаток от деления на 10, это **единицы**: `14 % 10` = 4;
- 1 + 4 = 5 → число 14 пропускается.

В диапазоне 1–30 так пропускаются **5, 14, 23**.

### Пока сумма выведенных чисел не станет равна 42

```php
$sum = 0;
for ($i = 1; $i <= 30; $i++) {
    if ($i % 2 != 0) {
        continue;
    }
    echo $i, " ";
    $sum += $i;
    if ($sum == 42) {
        break;
    }
}
```

`$sum` — **накопитель**: до цикла он 0, на каждой итерации к нему прибавляется выведенное число. Как только сумма стала 42 — `break`.

Почему здесь выводятся только чётные: если выводить подряд 1, 2, 3…, сумма идёт так: 1, 3, 6, 10, 15, 21, 28, 36, **45**. Она перепрыгивает с 36 сразу на 45, ровно 42 не бывает никогда, и цикл дошёл бы до 30. А сумма чётных: 2, 6, 12, 20, 30, **42** — попадает точно. Поэтому условие «сумма равна 42» скомбинировано с пропуском нечётных — заодно видно, что `continue` и `break` работают в одном цикле.

Результат: `2 4 6 8 10 12 (сумма = 42)`.

### Пока длина вывода не превысит 5 значений

```php
$count = 0;
$i = 1;
while ($i <= 30) {
    echo $i, " ";
    $count++;
    if ($count == 5) {
        break;
    }
    $i++;
}
```

`$count` — **счётчик** выведенных значений. После пятого числа `break`. Результат: `1 2 3 4 5`.

Здесь использован `while`, а не `for`, — чтобы показать, что любой `for` можно переписать через `while`: начало (`$i = 1`) пишется до цикла, условие — в скобках `while`, шаг (`$i++`) — в конце тела.

## Задание 5 — башенка одним циклом

Нужно получить (для 4 этажей):

```
////1\\\\
///222\\\
//33333\\
/4444444\
```

### Закономерность

| Этаж `$floor` | Черт с каждой стороны | Цифр в середине |
|---|---|---|
| 1 | 4 | 1 |
| 2 | 3 | 3 |
| 3 | 2 | 5 |
| 4 | 1 | 7 |

- **Черт с каждой стороны** уменьшается на 1 с каждым этажом: `$floors - $floor + 1`. Для 4 этажей: 4−1+1 = 4, 4−2+1 = 3, …
- **Цифр** — нечётные числа 1, 3, 5, 7: `2 * $floor - 1`.

### Решение

```php
for ($floor = 1; $floor <= $floors; $floor++) {
    $edge = $floors - $floor + 1;
    echo str_repeat("/", $edge)
        . str_repeat($floor, 2 * $floor - 1)
        . str_repeat("\\", $edge)
        . "\n";
}
```

`str_repeat($строка, $сколько_раз)` — повторить строку N раз: `str_repeat("/", 3)` → `"///"`. Именно она позволяет обойтись **одним** циклом: без неё на каждый этаж понадобились бы ещё вложенные циклы для черт и цифр.

`"\\"` — это **один** обратный слеш. В строке PHP `\` — специальный символ (с него начинаются `\n`, `\t`), поэтому сам слеш нужно записать дважды. Это называется **экранирование**.

Число этажей случайное — от 3 до 9. Больше 9 нельзя: номер этажа стал бы двузначным (`10`), и башня поехала бы.

## Задание 6 — проверка пароля

### Символы строки по индексу

К отдельному символу строки обращаются так же, как к элементу массива:

```php
$password = "Abc1";
$password[0];  // "A"
$password[3];  // "1"
```

Поэтому перебрать все символы можно циклом от 0 до `strlen($password) - 1`:

```php
for ($i = 0; $i < strlen($password); $i++) {
    $char = $password[$i];
    ...
}
```

Это работает только для однобайтовых символов (латиница, цифры) — см. теорию ЛР5. Для пароля этого достаточно.

### Флаги

```php
$hasDigit = false;
$hasUpper = false;
for (...) {
    if (ctype_digit($char)) {
        $hasDigit = true;
    }
    if (ctype_upper($char)) {
        $hasUpper = true;
    }
}
```

**Флаг** — переменная `true`/`false`, которая запоминает, случилось ли что-то. Сначала флаг опущен (`false`: «цифры пока не видели»). Если в цикле встретилась хоть одна цифра — флаг поднимаем (`true`). Обратно в `false` его никто не ставит, поэтому после цикла `$hasDigit === true` значит «цифра была хотя бы одна».

- `ctype_digit($char)` — `true`, если символ — цифра 0–9;
- `ctype_upper($char)` — `true`, если символ — заглавная латинская буква A–Z. Русские заглавные она не распознает.

### Сбор ошибок в массив

```php
$errors = [];
if (strlen($password) <= 8) {
    $errors[] = "длина должна быть больше 8 символов";
}
...
return $errors;
```

Вместо «правильно / неправильно» функция возвращает **список всех нарушений**. Пустой массив — нарушений нет, пароль корректный. Это удобнее для пользователя: он сразу видит все проблемы, а не исправляет их по одной.

«Больше 8 символов» — значит 9 и больше. Ошибка — когда длина **меньше или равна** 8, отсюда `<= 8`.

## Задание 7 — колода карт: даты и `switch`

### Даты в PHP — `DateTimeImmutable`

Считать возраст вручную (вычесть годы, потом поправить на месяц и день…) неудобно и легко ошибиться. В PHP для дат есть готовый класс:

```php
$birth = new DateTimeImmutable("2010-05-14");  // дата из строки "ГГГГ-ММ-ДД"
$today = new DateTimeImmutable("today");       // сегодня, время 00:00
```

`new` создаёт объект (ЛР2, задание 9). Объект даты умеет сравнивать даты и сдвигать их.

### Разница между датами — `diff`

```php
$birth->diff($today)
```

Возвращает объект-интервал (`DateInterval`) — «сколько прошло от одной даты до другой». У него есть свойства:

- `->y` — полных лет;
- `->m` — месяцев (сверх полных лет);
- `->d` — дней (сверх полных месяцев).

Поэтому `$birth->diff($today)->y` — это ровно **возраст в полных годах**, с учётом того, был ли уже день рождения в этом году.

### Сколько осталось до 18

```php
$adultDay = $birth->modify("+18 years");  // дата 18-летия
$wait = $today->diff($adultDay);
echo "{$wait->y} лет, {$wait->m} мес., {$wait->d} дн.";
```

1. `modify("+18 years")` — сдвинуть дату на 18 лет вперёд. Это день, когда человеку исполнится 18.
2. `$today->diff($adultDay)` — интервал от сегодня до этого дня.

Почему `DateTimeImmutable`, а не просто `DateTime`: «immutable» значит «неизменяемый». `modify` **не меняет** `$birth`, а возвращает **новый** объект. У обычного `DateTime` метод `modify` изменил бы сам `$birth`, и дата рождения испортилась бы.

Условие задания «старше 18» понято как «исполнилось 18 полных лет» (`$age < 18` → нельзя).

### `switch`

`switch` удобен, когда одну переменную нужно сравнить со списком конкретных значений:

```php
switch ($suit) {
    case 1:
        echo "♠ пики";
        break;
    case 2:
        echo "♥ червы";
        break;
    ...
}
```

1. PHP сравнивает `$suit` с каждым `case` по очереди.
2. Найдя совпадение, начинает выполнять код **с этого места**.
3. `break` — выйти из `switch`.

`break` в каждом `case` **обязателен**, если нужен только один вариант. Без него выполнение «провалится» в следующие `case` — подробно это используется в Части 2, задании 4.

Через `if/elseif` это выглядело бы как `if ($suit == 1) … elseif ($suit == 2) …` — тоже правильно, но `switch` короче и нагляднее, когда сравнивается одна и та же переменная.

# ЧАСТЬ 2

## Задание 1 — что выведется и почему

### # 1 — `match` сравнивает строго

```php
echo match (4) {
    '4' => 'string',
    4 => 'int',
    default => 'none'
};
```

`match` — «сопоставление»: берёт значение в скобках и ищет ветку, слева от `=>` в которой стоит такое же значение. Возвращает то, что справа.

Главное свойство: `match` сравнивает **строго**, через `===` — значение **и тип** должны совпасть.

- `4 === '4'` → `false`: число и строка — разные типы.
- `4 === 4` → `true`.

Результат: **`int`**.

У `switch` было бы иначе: он сравнивает нестрого (`==`), `4 == '4'` → `true`, и выбрался бы первый вариант — `string`.

### # 2 — `continue 2` внутри `switch`

```php
$items = [1, 2, 'stop', 4];
foreach ($items as $item) {
    switch ($item) {
        case 'stop':
            continue 2;
        default:
            echo $item;
    }
    echo $item;
}
```

`foreach ($массив as $элемент)` — перебрать массив: на каждой итерации в `$item` попадает очередной элемент.

`default` в `switch` — ветка «во всех остальных случаях».

Для элемента, не равного `'stop'`, выполняется `default` → `echo $item`, затем `switch` заканчивается, и выполняется второй `echo $item` после него. Значит, каждое число печатается **дважды**.

Для `'stop'` выполняется `continue 2`.

**Почему `2`.** Для `continue` и `break` PHP считает `switch` таким же уровнем вложенности, как цикл. Число после команды — сколько уровней «пробить»:

- `continue` (= `continue 1`) — относится к самому `switch`. Внутри `switch` он работает как `break`: просто выйти из `switch`. Тогда выполнился бы второй `echo $item`, и вывелось бы `stop`.
- `continue 2` — пропустить уровень `switch` и перейти к следующей итерации **внешнего** `foreach`. Второй `echo` для `'stop'` не выполнится.

| Элемент | Что происходит | Вывод |
|---|---|---|
| 1 | default → echo, потом echo после switch | `11` |
| 2 | так же | `22` |
| `'stop'` | `continue 2` → сразу к следующему элементу | — |
| 4 | default → echo, потом echo после switch | `44` |

Результат: **`112244`**.

### # 3 — `require_once` подключает файл только один раз

```php
// header.php
echo 'Я файл header';

// lab7.php
require_once 'header.php';
require_once 'header.php';
echo 'Готово';
```

`require 'файл.php'` — **вставить и выполнить** код из другого файла прямо в этом месте. Как будто содержимое файла скопировали сюда.

`_once` — «один раз»: PHP запоминает, какие файлы уже подключены. Если файл уже был подключён, повторный `require_once` ничего не делает.

1. Первый `require_once` — выполняет `header.php`, печатает `Я файл header`.
2. Второй — видит, что файл уже подключали, и пропускает его.
3. `echo 'Готово'`.

Результат: **`Я файл headerГотово`**. С обычным `require` было бы `Я файл headerЯ файл headerГотово`.

Зачем это нужно: если файл объявляет функцию, повторное подключение вызвало бы ошибку «функция уже объявлена». `_once` защищает от этого.

### # 4 — `include` и `require` для несуществующего файла

```php
include 'nothing.php';
echo 'После include';
require 'nothing.php';
echo 'После require';
```

Разница между `include` и `require` — только в реакции на ошибку, когда файла нет:

| | `include` | `require` |
|---|---|---|
| файла нет | предупреждение (`Warning`) | фатальная ошибка (`Fatal error`) |
| скрипт после ошибки | **продолжается** | **останавливается** |

Что происходит:

1. `include 'nothing.php'` — файла нет → `Warning`, но скрипт идёт дальше.
2. Печатается **`После include`**.
3. `require 'nothing.php'` — файла нет → `Fatal error`, скрипт останавливается.
4. `После require` **не печатается никогда**.

Поэтому этот пример вынесен в отдельный файл `include_demo.php` и показан на странице в рамке (`<iframe>`). Если бы он стоял прямо в `lab7.php`, страница оборвалась бы на этом месте, и все задания ниже не вывелись бы.

Если у тебя в MAMP выключен показ ошибок (`display_errors`), в рамке будет видно только «После include» — без текстов предупреждений. Сама логика при этом та же.

Когда что использовать:

- `require` — для файлов, без которых страница не может работать (стили, настройки, функции);
- `include` — для необязательных частей: если их нет, остальная страница пусть всё равно покажется.

## Задание 2 — вошёл ли пользователь и админ ли он

### Константа

```php
const ADMIN = "Влад";
```

**Константа** — именованное значение, которое нельзя изменить после объявления. Пишется **без** `$`. По соглашению имена констант пишут ЗАГЛАВНЫМИ буквами.

Второй способ объявить константу — функция `define("ADMIN", "Влад");`.

### `null` — «значения нет»

`$user = null` значит, что пользователь не вошёл — имени нет. Проверяем строго: `$user === null`.

### Альтернативный синтаксис

Обычно блоки условий пишут в фигурных скобках. Альтернативный синтаксис заменяет `{` на `:`, а закрывающую `}` — на слово `endif;`:

```php
// обычный
if ($a) {
    ...
} elseif ($b) {
    ...
} else {
    ...
}

// альтернативный
if ($a):
    ...
elseif ($b):
    ...
else:
    ...
endif;
```

Так же для циклов: `foreach (...): … endforeach;`, `for (...): … endfor;`, `while (...): … endwhile;`, `switch (...): … endswitch;`.

Зачем: альтернативный синтаксис удобен, когда условие **перемешано с HTML**. Слово `endif` или `endforeach` легче найти среди тегов, чем одинокую `}`.

### Решение

```php
<?php foreach ($users as $user): ?>
    <p>
        $user = <?= var_export($user, true) ?> →
        <?php if ($user === null): ?>
            пользователь не вошёл в систему
        <?php elseif ($user === ADMIN): ?>
            вошёл администратор <b><?= $user ?></b>
        <?php else: ?>
            вошёл пользователь <?= $user ?>, но он не администратор
        <?php endif; ?>
    </p>
<?php endforeach; ?>
```

PHP закрывается (`?>`) и открывается снова между ветками. Всё, что между тегами, — обычный HTML. Он выводится, только если выполнилась соответствующая ветка.

`<?= $user ?>` — короткая запись `<?php echo $user; ?>` (ЛР1).

Порядок проверок важен:

1. Сначала `null` — не вошёл.
2. Потом `=== ADMIN` — администратор.
3. Иначе — вошёл, но обычный пользователь.

`foreach` по массиву `[null, "Пётр", "Влад"]` проверяет все три случая за один проход.

## Задание 3 — камеры и средняя цена

### `foreach`

```php
foreach ($массив as $значение) { ... }
foreach ($массив as $ключ => $значение) { ... }
```

Перебирает массив от первого элемента до последнего. На каждой итерации в переменную попадает очередной элемент. Вторая форма даёт ещё и ключ. Счётчик `$i` и проверка длины, как в `for`, не нужны.

### Вложенный `foreach`

```php
foreach ($cameras as $camera) {
    $prices = "";
    foreach ($camera['prices'] as $price) {
        $prices .= $price . " ";
    }
    $average = array_sum($camera['prices']) / count($camera['prices']);
    ...
}
```

1. **Внешний** цикл перебирает камеры. В `$camera` — массив вида `['title' => ..., 'prices' => [...]]`.
2. **Внутренний** цикл перебирает цены **текущей** камеры и склеивает их в строку через `.=` (дописать в конец).
3. **Среднее** = сумма / количество: `array_sum` (ЛР6) делим на `count`.

Результат выводится HTML-таблицей (`<table>`, `<tr>`, `<td>` — как в ЛР2, задание 4). Средняя цена округлена до 2 знаков через `round`.

## Задание 4 — цвета через `switch` в альтернативном синтаксисе

### Альтернативный синтаксис `switch`

```php
switch ($first):
    case 1:
        echo "красный";
        break;
    ...
endswitch;
```

`{` → `:`, `}` → `endswitch;`.

У альтернативного `switch` есть ловушка: между `switch (...):` и первым `case` **не должно быть никакого вывода**, даже пробела или перевода строки в HTML. Если написать

```php
<?php switch ($n): ?>
    <?php case 1: ?>
```

будет синтаксическая ошибка: перевод строки между `?>` и `<?php` — это вывод. Поэтому в лабе весь `switch` написан внутри одного блока `<?php ... ?>`.

### «Проваливание» (fall-through)

Вспомним: `switch` находит совпавший `case` и начинает выполнять код **с этого места**. Останавливает его только `break`.

**С `break` в каждом `case`** — выполняется ровно один вариант. Выпало 3 → `жёлтый`.

**Без `break`** — после совпавшего `case` выполнение идёт дальше, через все следующие `case`, до конца `switch`:

```php
switch ($second):
    case 1:
        echo "красный ";
    case 2:
        echo "оранжевый ";
    case 3:
        echo "жёлтый ";
    case 4:
        echo "зелёный ";
    case 5:
        echo "синий ";
endswitch;
```

Выпало 3 → вход в `case 3`, дальше без остановки → `жёлтый зелёный синий`.

Это и есть «особенность конструкции switch» из условия задания. Обычно забытый `break` — это ошибка, но здесь проваливание использовано специально.

## Задание 5 — месяц и время года через `match`

```php
$season = match ($month) {
    12, 1, 2 => "зимний месяц",
    3, 4, 5 => "весенний месяц",
    6, 7, 8 => "летний месяц",
    9, 10, 11 => "осенний месяц",
    0 => "0 — такого месяца не существует",
};
```

### Чем `match` отличается от `switch`

| | `switch` | `match` |
|---|---|---|
| сравнение | нестрогое `==` | строгое `===` |
| возвращает значение | нет | **да** — результат можно сразу записать в переменную |
| `break` | нужен в каждом `case` | не нужен, проваливания нет |
| несколько значений в одной ветке | несколько `case` подряд | через запятую: `12, 1, 2 =>` |
| нет подходящей ветки | ничего не произойдёт | **ошибка** `UnhandledMatchError` |

### Несколько значений в ветке

`12, 1, 2 => "зимний месяц"` — ветка подходит, если `$month` равен 12, **или** 1, **или** 2.

### Обработка 0

Из условия число может быть от 0 до 12, а месяца 0 не бывает. Если бы для 0 не было ветки, `match` выбросил бы `UnhandledMatchError` — скрипт бы упал. Поэтому у 0 своя ветка с пояснением.

Ветки `default` нет специально: все значения 0–12 перечислены, и других `rand(0, 12)` не выдаст. Если бы на вход могло прийти, например, 13, понадобилась бы ветка `default => "некорректное число"`.

## Задание 6 — главная страница из частей

### Зачем разбивать страницу на файлы

Когда на сайте много страниц, у них часто общие куски: `<head>` со стилями, меню, шапка, подвал. Если копировать их в каждую страницу, то, чтобы поправить меню, придётся править каждый файл. Вынесенный в отдельный файл кусок правится **в одном месте**, а все страницы подключают его через `require`/`include`.

### Как устроена главная страница теперь

```php
<html>

<?php require 'head.html'; ?>

<body>
    <?php include 'header.html'; ?>
    <?php require 'nav.html'; ?>
    <?php include 'footer.html'; ?>
</body>

</html>
```

| Файл | Что внутри | Подключение | Почему так |
|---|---|---|---|
| `head.html` | `<head>`: кодировка, заголовок вкладки, все стили | `require` | без стилей страница сломана |
| `nav.html` | все ссылки на лабораторные | `require` | без меню на главной нет смысла |
| `header.html` | шапка: название предмета и лектор | `include` | без шапки страница всё ещё работает |
| `footer.html` | подвал: год и ФИО | `include` | без подвала страница всё ещё работает |

Теперь новая лабораторная добавляется правкой **только** `nav.html`.

### Подключённый файл выполняется как PHP, даже если он `.html`

В `footer.html` написано:

```php
<?= date("Y") ?> · Жолудь В.А.
```

`date("Y")` — текущий год четырьмя цифрами. Год меняется сам, править его каждый январь не нужно.

Хотя файл называется `.html`, при подключении через `require`/`include` PHP **выполняет** его как PHP-код. Расширение файла на это не влияет. Если открыть `footer.html` в браузере напрямую, PHP-код не выполнится — но напрямую его и не открывают, он нужен только как часть `index.php`.

### Пути при подключении

`require 'head.html'` ищет файл относительно папки, в которой лежит `index.php`. Поэтому все четыре файла лежат в корне сайта рядом с `index.php`.

## Шпаргалка

| Конструкция | Что делает | Пример |
|---|---|---|
| `if / elseif / else` | выполнить один из блоков по условию | `if ($a > 0) {...} else {...}` |
| `for` | цикл со счётчиком | `for ($i = 0; $i < 5; $i++) {...}` |
| `while` | цикл, пока условие истинно (проверка до тела) | `while ($i < 5) {...}` |
| `do-while` | то же, но проверка после тела, минимум 1 раз | `do {...} while ($i < 5);` |
| `foreach` | перебор массива | `foreach ($arr as $k => $v) {...}` |
| `break` | выйти из цикла / `switch` | `if ($x) break;` |
| `continue` | перейти к следующей итерации | `if ($x) continue;` |
| `break N` / `continue N` | то же, но на N уровней вложенности | `continue 2;` |
| `switch` | выбор по значению, нестрогое `==`, нужен `break` | `switch ($x) { case 1: ...; break; }` |
| `match` | выбор по значению, строгое `===`, возвращает результат | `$y = match ($x) { 1, 2 => 'a', default => 'b' };` |
| альтернативный синтаксис | `:` вместо `{`, `endif;` вместо `}` | `if ($a): ... endif;` |
| `include` | подключить файл; нет файла → Warning, скрипт идёт дальше | `include 'footer.html';` |
| `require` | подключить файл; нет файла → Fatal error, скрипт стоп | `require 'head.html';` |
| `include_once` / `require_once` | то же, но не подключать повторно | `require_once 'header.php';` |
| `const` / `define` | объявить константу | `const ADMIN = "Влад";` |
| `str_repeat` | повторить строку N раз | `str_repeat("/", 3)` → `"///"` |
| `ctype_digit` / `ctype_upper` | символ — цифра / заглавная латинская буква | `ctype_digit("7")` → `true` |
| `DateTimeImmutable` | объект даты | `new DateTimeImmutable("2010-05-14")` |
| `->diff()` | разница между датами (`->y`, `->m`, `->d`) | `$birth->diff($today)->y` |
| `->modify()` | сдвинуть дату | `$birth->modify("+18 years")` |
| `date("Y")` | текущий год | `2026` |
