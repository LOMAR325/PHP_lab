## 0. Основа

### Регулярное выражение — шаблон строки

**Регулярное выражение** (регулярка, regex) — это описание того, как должна выглядеть строка.

Аналогия — бланк с клеточками. На бланке написано: «три цифры, дефис, две цифры». Любую строку можно приложить к бланку и сразу сказать, подходит она или нет:

```
шаблон:  три цифры, дефис, две цифры
"123-45"   → подходит
"12-345"   → не подходит
"abc-de"   → не подходит
```

Регулярка — тот же бланк, только записанный специальными символами:

```php
'/^\d{3}-\d{2}$/'
```

С регуляркой можно делать три вещи:

1. **проверить**, подходит ли строка целиком (правильный ли email) — задания 1, 5, 8;
2. **найти** в строке все подходящие куски (все числа в тексте) — задания 3, 6;
3. **заменить** найденные куски на другие (убрать `<script>`, переставить части даты) — задания 2, 4, 7.

### Как записать шаблон в PHP

В PHP регулярка — обычная строка такого вида:

```php
'/шаблон/модификаторы'
```

- `/` в начале и в конце — **разделители**. Они показывают, где шаблон начинается и заканчивается.
- После закрывающего `/` можно дописать **модификаторы** — буквы, которые меняют поведение всего шаблона. Например, `u` — «в строке кириллица».

```php
'/^\d{3}$/'     // без модификаторов
'/^[а-я]+$/u'   // с модификатором u
```

Разделителем может быть почти любой символ, не только `/`. Если в шаблоне много слешей (пути, ссылки), удобнее взять `#`, тогда слеши не придётся экранировать:

```php
preg_replace('#/+#', '/', 'a//b///c');   // a/b/c
```

Шаблон пишут в **одинарных** кавычках. В двойных PHP сам начнёт разбирать `\n`, `$1` и т.п. ещё до того, как строка попадёт в регулярку.

### Обычные символы и метасимволы

Буквы и цифры в шаблоне означают сами себя: шаблон `/cat/` ищет буквы `c`, `a`, `t` подряд.

Но некоторые символы — **метасимволы**: у них особый смысл.

```
.  ^  $  *  +  ?  {  }  [  ]  (  )  |  \
```

Чтобы метасимвол означал сам себя, перед ним ставят обратный слеш `\` — это называется **экранирование**:

| Нужно найти | Пишем | Почему                             |
| ----------- | ----- | ---------------------------------- |
| точку       | `\.`  | просто `.` — «любой символ»        |
| плюс        | `\+`  | просто `+` — «один или больше раз» |
| скобку      | `\(`  | просто `(` — начало группы         |
| слеш        | `\/`  | просто `/` закончит шаблон         |

Например, телефон `+375 (29)` в шаблоне превращается в `\+375 \(29\)`.

### Классы символов `[...]` — один символ из набора

Квадратные скобки означают **один** символ из перечисленных:

| Запись | Что подходит |
|---|---|
| `[abc]` | `a`, `b` или `c` |
| `[a-z]` | любая строчная латинская буква (диапазон) |
| `[0-9]` | любая цифра |
| `[A-Za-z0-9]` | латинская буква любого регистра или цифра |
| `[а-яё]` | строчная русская буква (нужен модификатор `u`) |
| `[^0-9]` | любой символ, **кроме** цифры (`^` в начале скобок — «не») |

Две особенности:

- **Ё стоит отдельно** от остального алфавита, поэтому её дописывают вручную: `[А-ЯЁа-яё]`. Иначе `Пётр` не пройдёт проверку.
- Внутри `[]` почти все метасимволы становятся обычными: `[.?*]` — это просто точка, вопрос или звёздочка. Особые там только `^` в начале, `-` между символами, `]` и `\`. Дефис как символ ставят в конец: `[a-z-]`.

### Готовые классы — короткие записи

| Запись              | Что подходит                                           | То же самое    |
| ------------------- | ------------------------------------------------------ | -------------- |
| `\d`                | цифра                                                  | `[0-9]`        |
| `\w`                | латинская буква, цифра или `_`                         | `[A-Za-z0-9_]` |
| `\s`                | пробельный символ: пробел, табуляция, перевод строки   |                |
| `\D`, `\W`, `\S`    | всё, **кроме** `\d`, `\w`, `\s`                        |                |
| `.`                 | любой символ, кроме перевода строки                    |                |
| `\p{L}`             | любая буква любого алфавита (нужен `u`)                |                |
| `\p{Lu}` / `\p{Ll}` | заглавная / строчная буква любого алфавита (нужен `u`) |                |

### Квантификаторы — сколько раз

Квантификатор ставится **после** символа или группы и говорит, сколько раз этот символ может повториться:

| Квантификатор | Сколько раз | Пример | Подходит |
|---|---|---|---|
| `?` | 0 или 1 | `-?\d` | `5`, `-5` |
| `*` | 0 и больше | `\d*` | пусто, `7`, `123` |
| `+` | 1 и больше | `\d+` | `7`, `123`, но не пусто |
| `{3}` | ровно 3 | `\d{3}` | `123` |
| `{2,}` | 2 и больше | `\d{2,}` | `12`, `12345` |
| `{4,20}` | от 4 до 20 | `[a-z]{4,20}` | от 4 до 20 строчных букв |

Квантификатор действует только на **один** элемент перед ним: в `ab+` повторяется только `b` (`abbb`). Чтобы повторить кусок, его берут в скобки: `(ab)+` — `ababab`.

### Якоря `^`, `$`, `\b` — позиции

Якорь — это не символ, а **место** в строке:

| Якорь | Место                                    |
| ----- | ---------------------------------------- |
| `^`   | начало строки                            |
| `$`   | конец строки                             |
| `\b`  | граница слова — между буквой и не-буквой |
|       |                                          |

**Без якорей регулярка ищет совпадение где угодно внутри строки**:

```php
preg_match('/\d{3}/', 'abc12345');     // 1 — три цифры нашлись в середине
preg_match('/^\d{3}$/', 'abc12345');   // 0 — строка целиком не «три цифры»
```

Поэтому при проверке поля формы шаблон **всегда** оборачивают в `^...$`: «от начала до конца строка должна быть такой».

### Группы `( )` и «или» `|`

Круглые скобки делают две вещи:

1. **объединяют** кусок, чтобы к нему применить квантификатор или «или»: `(ab)+`, `(com|ru|by)`;
2. **запоминают**, что в них попало, — потом это можно достать (задания 6 и 7).

`|` — «или»: `com|ru|by` — одно из трёх.

У `|` самый низкий приоритет: он делит **весь** шаблон, если его не ограничить скобками:

```php
'/^\.com|ru|by$/'      // неправильно: «^.com» ИЛИ «ru» ИЛИ «by$»
'/\.(com|ru|by)$/'     // правильно: точка, потом одно из трёх, потом конец
```

Если запоминать не нужно, а только объединить, пишут `(?: ... )` — **незахватывающая** группа: `\.(?:com|ru|by)$`.

### Модификаторы

| Модификатор | Что делает                                                             |
| ----------- | ---------------------------------------------------------------------- |
| `i`         | не различать регистр: `/php/i` найдёт и `PHP`                          |
| `u`         | строка в UTF-8 — **обязателен, если в шаблоне или строке кириллица**   |
| `s`         | точка `.` ловит и перевод строки                                       |
| `m`         | `^` и `$` — начало и конец **каждой строки** текста, а не всего текста |
| `x`         | пробелы и комментарии `#` внутри шаблона игнорируются                  |
|             |                                                                        |
|             |                                                                        |

Модификаторы можно комбинировать: `/.../su`.

### Кириллица и модификатор `u`

В кодировке UTF-8 русская буква занимает **2 байта**. Без `u` регулярка работает с байтами и «видит» в слове `дом` шесть символов вместо трёх:

```php
preg_match('/^.{3}$/', 'дом');            // 0 — для байтов это 6 символов
preg_match('/^.{3}$/u', 'дом');           // 1
preg_match('/^[А-ЯЁ][а-яё]*$/', 'Иван');  // 0 — диапазон ломается
preg_match('/^[А-ЯЁ][а-яё]*$/u', 'Иван'); // 1
```

Правило простое: есть русские буквы — ставь `u`.

### Как читать готовый шаблон

Длинная регулярка читается слева направо, кусок за куском. Например, телефон из задания 1:

```php
'/^8 0(?:29|33|44) \d{3}-\d{3}-\d{2}$/'
```

| Кусок            | Значит                             |
| ---------------- | ---------------------------------- |
| `^`              | начало строки                      |
| `8 0`            | буквально «8», пробел, «0»         |
| `(?:29\|33\|44)` | 29, 33 или 44                      |
| ` `              | пробел                             |
| `\d{3}`          | три цифры                          |
| `-`              | дефис (вне `[]` он обычный символ) |
| `\d{3}-\d{2}`    | три цифры, дефис, две цифры        |
| `$`              | конец строки                       |

Подходит `8 029 111-111-11`, не подходит `8 025 111-111-11` (код 25) и `8 029 11111111` (нет дефисов).

## Задание 1 — проверка данных формы

> Создайте форму с текстовыми полями и кнопкой submit. Проверьте ФИО, дату рождения, почту и телефон.

### `preg_match($шаблон, $строка, $совпадения)` — подходит ли строка

```php
preg_match('/^\d{3}$/', '123');   // 1
preg_match('/^\d{3}$/', '12a');   // 0
```

Ищет **первое** совпадение шаблона в строке. Возвращает:

- `1` — нашлось;
- `0` — не нашлось;
- `false` — ошибка в самом шаблоне (например, незакрытая скобка).

Обрати внимание: возвращается **число**, а не `true`/`false`. В `if` это работает как обычно: `1` — истина, `0` — ложь.

Третий аргумент необязательный. Если его передать, туда запишется найденное: `$m[0]` — всё совпадение, `$m[1]`, `$m[2]`… — то, что попало в скобки (это понадобится в заданиях 4 и 6).

```php
preg_match('/(\d{2})\.(\d{2})/', 'Дата: 12.11', $m);
// $m = ["12.11", "12", "11"]
```

### ФИО

> Все слова начинаются с большой буквы и имеют в длину хотя бы один символ кириллицы или латиницы, цифр быть не должно.

```php
'/^[A-ZА-ЯЁ][a-zа-яё]*(?: [A-ZА-ЯЁ][a-zа-яё]*)*$/u'
```

| Кусок                       | Значит                                                                 |
| --------------------------- | ---------------------------------------------------------------------- |
| `[A-ZА-ЯЁ]`                 | первая буква слова — заглавная, латинская или русская                  |
| `[a-zа-яё]*`                | дальше ноль или больше строчных букв (слово может быть из одной буквы) |
| `(?: [A-ZА-ЯЁ][a-zа-яё]*)*` | ноль или больше раз: пробел + ещё одно такое же слово                  |
| `u`                         | в шаблоне кириллица                                                    |

Подходит: `Иванов Иван Иванович`, `Ёжиков Пётр`. Не подходит: `иванов` (маленькая), `Иван2` (цифра), `Иван  Иванов` (два пробела).

### Дата рождения

> В формате 01.01.1970 — день и месяц обязательно из двух цифр, между частями даты точки.

```php
'/^\d{2}\.\d{2}\.\d{4}$/'
```

Точка экранирована: `\.` — именно точка, а не «любой символ». Без экранирования прошла бы и `01-01-1970`.

Подходит: `01.01.1970`. Не подходит: `1.01.1970` (день из одной цифры), `31-12-2000` (дефисы).

Строже — чтобы день был от 01 до 31, а месяц от 01 до 12:

```php
'/^(0[1-9]|[12]\d|3[01])\.(0[1-9]|1[0-2])\.\d{4}$/'
```

Регулярка не умеет считать, поэтому числа задают «по разрядам»: `0[1-9]` — 01–09, `[12]\d` — 10–29, `3[01]` — 30 и 31. Но 31.02 всё равно пройдёт: что такой даты нет, регулярка не знает. Для этого есть `checkdate()`.

### Электронная почта

> first@second.third: first — от 4 до 20 латинских букв и цифр; second — от 2 до 10 только латинских букв нижнего регистра; third — только com, ru или by.

```php
'/^[a-zA-Z0-9]{4,20}@[a-z]{2,10}\.(?:com|ru|by)$/'
```

| Кусок | Часть адреса |
|---|---|
| `[a-zA-Z0-9]{4,20}` | first: 4–20 латинских букв и цифр |
| `@` | собака — обычный символ |
| `[a-z]{2,10}` | second: 2–10 строчных латинских букв |
| `\.` | точка |
| `(?:com\|ru\|by)` | third: одно из трёх |

Подходит: `vlad2005@gmail.com`. Не подходит: `abc@mail.ru` (first короче 4), `student1@Bstu.by` (заглавная в second), `student1@bstu.org` (не та зона), `vlad_2005@mail.ru` (`_` не разрешён).

### Телефон

> 8 029 111-111-11, коды оператора только 29, 44 или 33.

```php
'/^8 0(?:29|33|44) \d{3}-\d{3}-\d{2}$/'
```

Разобран по кусочкам в «Как читать готовый шаблон» (раздел 0). Пробелы и дефисы в шаблоне стоят буквально — значит, и в строке они должны быть ровно на этих местах.

### Как это собрано

Правила удобно хранить в одном массиве и проверять одним циклом — так не забудешь ни одно поле:

```php
$rules = [
    'fio'   => ['/^[A-ZА-ЯЁ][a-zа-яё]*(?: [A-ZА-ЯЁ][a-zа-яё]*)*$/u', 'Каждое слово с заглавной буквы, без цифр'],
    'birth' => ['/^\d{2}\.\d{2}\.\d{4}$/', 'Формат 01.01.1970'],
    'email' => ['/^[a-zA-Z0-9]{4,20}@[a-z]{2,10}\.(?:com|ru|by)$/', 'Формат first@second.third'],
    'phone' => ['/^8 0(?:29|33|44) \d{3}-\d{3}-\d{2}$/', 'Формат 8 029 111-111-11'],
];
$values = [];
$errors = [];

if ($_SERVER['REQUEST_METHOD'] === 'POST') {
    foreach ($rules as $field => [$regex, $message]) {
        $values[$field] = trim($_POST[$field] ?? '');
        if (!preg_match($regex, $values[$field])) {
            $errors[$field] = $message;
        }
    }
}
```

По строкам:

1. `$rules` — для каждого поля шаблон и текст ошибки.
2. `$_SERVER['REQUEST_METHOD'] === 'POST'` — форму действительно отправили (ЛР9).
3. `foreach ($rules as $field => [$regex, $message])` — перебираем поля; `[$regex, $message]` сразу раскладывает пару на две переменные (деструктуризация, ЛР6).
4. `trim(...)` — убрать случайные пробелы по краям, иначе `" 01.01.1970"` не пройдёт `^`.
5. `?? ''` — если поля нет в `$_POST`, берём пустую строку.
6. `!preg_match(...)` — не подошло → записываем ошибку для этого поля.

В форме значение выводят обратно через `htmlspecialchars`, чтобы пользователю не пришлось вводить всё заново, а ошибку показывают рядом с полем:

```php
<input name="email" value="<?= htmlspecialchars($values['email'] ?? '') ?>">
<span style="color: red"><?= $errors['email'] ?? '' ?></span>
```

### Почему не хватит проверки в браузере

У `<input>` есть атрибут `pattern="..."` — браузер сам проверит поле перед отправкой. Но его легко обойти: убрать атрибут в DevTools или отправить запрос без формы. Поэтому проверка на сервере через `preg_match` обязательна всегда, а `pattern` — только удобство для пользователя.

## Задание 2 — защита от XSS

> Создайте в отдельном файле heredoc-строку $xss, содержащую некоторый HTML и произвольный код на JavaScript. Подключите файл к основной странице. С помощью регулярного выражения обезопасьте строку и выведите содержимое на экран.

### Что такое XSS

**XSS** (межсайтовый скриптинг) — когда в страницу попадает чужой JavaScript. Например, пользователь пишет в комментарии `<script>...</script>`, сайт выводит комментарий как есть — и скрипт выполняется у **каждого**, кто открыл страницу. Так крадут куки и сессии.

Задача — вывести такую строку так, чтобы скрипт **не выполнился**.

### Файл со строкой — heredoc и подключение

Heredoc (ЛР5) удобен для многострочного HTML: кавычки внутри не нужно экранировать.

```php
// xss.php
<?php
$xss = <<<HTML
<h2>Привет</h2>
<p onclick="alert(1)">Текст</p>
<script>alert("Я весь такой злой и опасный...")</script>
HTML;
```

Подключение (ЛР8): `require "xss.php";` — после этой строки переменная `$xss` доступна в основном файле.

### `preg_replace($шаблон, $замена, $строка)` — заменить совпадения

```php
preg_replace('/\s+/', ' ', "a    b \n c");   // "a b c"
```

Находит **все** совпадения шаблона и заменяет их на `$замена`. Возвращает **новую** строку, исходная не меняется.

Если `$замена` — пустая строка `''`, найденное просто удаляется.

Можно передать **массивы** шаблонов и замен — тогда замены выполнятся по очереди, за один вызов:

```php
preg_replace(['/a/', '/b/'], ['1', '2'], 'abc');   // "12c"
```

### Способ 1 — вырезать опасное

```php
echo preg_replace([
    '/<script\b[^>]*>.*?<\/script>/is',
    '/\son\w+\s*=\s*("[^"]*"|\'[^\']*\')/i',
], '', $xss);
```

Первый шаблон — тег `<script>` целиком вместе с содержимым:

| Кусок | Значит |
|---|---|
| `<script` | начало тега |
| `\b` | граница слова — чтобы не зацепить, например, `<scripts>` |
| `[^>]*>` | любые атрибуты до закрывающей `>` |
| `.*?` | содержимое скрипта — **ленивый** квантификатор (ниже) |
| `<\/script>` | закрывающий тег; слеш экранирован, потому что `/` — разделитель |
| `i` | `<SCRIPT>` тоже сработает в браузере — ловим любой регистр |
| `s` | скрипт может занимать несколько строк — точка должна ловить переводы строк |

Второй шаблон — атрибуты-обработчики вроде `onclick="..."` и `onerror='...'`: пробел, `on`, буквы, `=`, значение в двойных или одинарных кавычках.

Результат: `<h2>Привет</h2><p>Текст</p>` — HTML остался, скрипты пропали.

### Жадный и ленивый квантификатор

По умолчанию `*` и `+` **жадные**: захватывают как можно **больше**. Если в строке два скрипта, жадный `.*` захватит всё от первого `<script>` до **последнего** `</script>` — вместе с нормальным текстом между ними.

Знак `?` после квантификатора делает его **ленивым**: захватить как можно **меньше**.

```php
preg_match('/<.+>/',  '<b>x</b>', $m);   // "<b>x</b>" — жадный дошёл до последней >
preg_match('/<.+?>/', '<b>x</b>', $m);   // "<b>"      — ленивый остановился на первой >
```

### Способ 2 — превратить `<` и `>` в безопасные символы

```php
echo preg_replace(['/</', '/>/'], ['&lt;', '&gt;'], $xss);
```

`&lt;` и `&gt;` — **HTML-сущности**: браузер показывает их как `<` и `>`, но тегами не считает. Весь HTML, включая скрипт, отобразится на странице как обычный текст.

### Почему в реальном коде — `htmlspecialchars`

Способ 1 легко обойти: `<img src=x onerror=alert(1)>` (без кавычек), `<svg onload=...>` и десятки других трюков. Чёрный список «что вырезать» никогда не бывает полным. Надёжно — способ 2, а в жизни для него есть готовая функция `htmlspecialchars($xss)` (ЛР9): она заменяет `<`, `>`, `"`, `'` и `&`. В лабе требуют именно регулярку, поэтому покажи оба способа и объясни, почему второй надёжнее.

## Задание 3 — четыре скрипта

### Убрать лишние пробелы

> Удалить пробелы из строки "М н о г о  п р о б е л о в", кроме тех, которые должны быть между словами.

Между буквами стоит **один** пробел, между словами — **два**. Значит: одиночный пробел удалить, двойной превратить в один.

```php
echo preg_replace('/ ( )?/', '$1', 'М н о г о  п р о б е л о в');   // Много пробелов
```

- ` ` — пробел;
- `( )?` — ещё один пробел, **необязательный**, и он запоминается в группу 1;
- замена `$1` — «то, что попало в группу 1».

Одиночный пробел: группа пустая → заменяется на пустоту → пробел исчез. Двойной: в группе второй пробел → два пробела заменяются на один.

`$1`, `$2`… в строке замены — ссылки на группы. Подробнее — в задании 7.

### `preg_match_all($шаблон, $строка, $совпадения)` — найти все совпадения

> Найти и вывести все числа в строке.

`preg_match` останавливается на первом совпадении, `preg_match_all` ищет **все**. Возвращает их количество, а сами совпадения кладёт в третий аргумент.

```php
preg_match_all('/-?\d+(?:[.,]\d+)?/', 'Цена 12.50, скидка -3, осталось 7 шт. и 1,5 кг', $m);
print_r($m[0]);   // [12.50, -3, 7, 1,5]
```

| Кусок | Значит |
|---|---|
| `-?` | необязательный минус |
| `\d+` | одна или больше цифр |
| `(?:[.,]\d+)?` | необязательная дробная часть: точка или запятая и цифры |

Как устроен результат: `$m[0]` — массив **всех найденных совпадений целиком**, `$m[1]` — массив того, что попало в первые скобки, и т.д. Поэтому выводят `$m[0]`. Группа здесь незахватывающая `(?: )`, чтобы не плодить лишний `$m[1]`.

Если нужны только целые числа без знака — достаточно `/\d+/`.

### Всё, что в кавычках, — даже через перевод строки

> Найти в стихотворении всё, что заключено в кавычки (обратите внимание на перевод строки), и записать результат в массив.

```php
preg_match_all('/“(.*?)”/su', $poem, $m);
print_r($m[1]);
// [если б я, маленький дом, Хундертвассера,
// И мы, в нём]
```

- `“` и `”` — «ёлочки-лапки» из текста задания, это **другие** символы, не `"`. Они не из латиницы, поэтому нужен `u`.
- `(.*?)` — всё внутри кавычек, **лениво**: до ближайшей закрывающей кавычки, а не до последней в стихотворении.
- `s` — главный подвох задания. Фраза «Хундертвассера, И мы» разорвана переводом строки, а точка без `s` перевод строки не ловит. Без `s` найдутся только 3 фразы из 4.
- Выводим `$m[1]` — содержимое скобок, **без** самих кавычек. В `$m[0]` были бы фразы вместе с кавычками.

Другой способ без `s` — класс «всё, кроме закрывающей кавычки»: `/“([^”]*)”/u`. Класс с `^` ловит и переводы строк.

### `preg_split($шаблон, $строка, $лимит, $флаги)` — разбить строку

> Разбить строку по знакам препинания . , : ; – (при этом не используйте explode()).

`explode` режет только по одному конкретному разделителю. `preg_split` режет по **шаблону** — то есть сразу по любому из знаков.

```php
print_r(preg_split('/\s*[.,:;–]\s*/u', 'Раз, два: три; четыре – пять.', -1, PREG_SPLIT_NO_EMPTY));
// [Раз, два, три, четыре, пять]
```

- `[.,:;–]` — один из знаков; внутри `[]` точка обычная. Тире `–` — не латинский символ, поэтому `u`.
- `\s*` по краям — вместе со знаком «съедаем» пробелы вокруг него, иначе части были бы `" два"`, `"четыре "`.
- `-1` — лимит частей: «без ограничения».
- `PREG_SPLIT_NO_EMPTY` — не возвращать пустые части. Строка кончается точкой, и после неё осталась бы пустая строка.

## Задание 4 — шаблон электронного письма

> Дан шаблон: `Good {time}, dear {name}! You look {prop} today!` Замените каждое слово в фигурных скобках на соответствующее из другого текста: `_evening_, **Friend**, PROP great PROP` (должны остаться только слова, без `_`, `**` и `PROP`). При этом используйте `preg_replace()`.

Задача в два шага: сначала **достать** слова из второго текста, потом **подставить** их в шаблон.

### Шаг 1 — достать слова группами

```php
$src = "_evening_, **Friend**, PROP great PROP";
preg_match('/_(\w+?)_.*?\*\*(\w+)\*\*.*?PROP (\w+) PROP/', $src, $w);
// $w[1] = "evening", $w[2] = "Friend", $w[3] = "great"
```

| Кусок | Значит |
|---|---|
| `_(\w+?)_` | слово между подчёркиваниями → группа 1 |
| `.*?` | всё, что между частями (запятые, пробелы) |
| `\*\*(\w+)\*\*` | слово между двумя звёздочками → группа 2. `*` — метасимвол, поэтому `\*` |
| `PROP (\w+) PROP` | слово между `PROP` → группа 3 |

Почему `\w+?` ленивый в первой группе: символ `_` тоже входит в `\w`. Жадный `\w+` съел бы и закрывающее подчёркивание, и шаблон не нашёл бы `_` после слова.

### Шаг 2 — подставить через `preg_replace` с массивами

```php
$tpl = "Good {time}, dear {name}! You look {prop} today!";
echo preg_replace(['/\{time\}/', '/\{name\}/', '/\{prop\}/'], [$w[1], $w[2], $w[3]], $tpl);
// Good evening, dear Friend! You look great today!
```

Массив шаблонов и массив замен: первый шаблон заменяется первым элементом замен, второй — вторым. Фигурные скобки экранированы: `{` и `}` — метасимволы (из них делают квантификаторы вида `{2,5}`).

В тексте задания написано `preg_repalce` — это опечатка, функция называется `preg_replace`.

## Задание 5 — пароль одной регуляркой

> Проверка пароля одним регулярным выражением: минимум 8 символов; символы разного регистра (кириллица и латиница); как минимум одна цифра и один спецсимвол `! @ # % ^ & *`; нет пробелов; нет двух и более одинаковых символов подряд.

### В чём сложность

Обычная регулярка описывает строку **слева направо**: «сначала это, потом то». А здесь нужно «**И** есть цифра, **И** есть заглавная, **И** есть спецсимвол» — в любом месте и в любом порядке. Для этого есть просмотр вперёд.

### Просмотр вперёд `(?=...)` — заглянуть, не двигаясь

`(?=X)` проверяет: «дальше в строке есть X». Но **позицию не сдвигает** и найденное в совпадение не включает.

Аналогия: стоишь у начала коридора, заглядываешь в него — есть ли где-то дверь с цифрой? — и остаёшься на месте. Потом заглядываешь снова — есть ли дверь с заглавной буквой? Каждая проверка начинается с того же места.

```php
'/^(?=.*\d)/'   // с начала строки: где-то дальше (.*) есть цифра (\d)
```

`.*` внутри — «сколько угодно любых символов», то есть «где угодно дальше». Несколько просмотров подряд — это «И»:

```php
'/^(?=.*\d)(?=.*[A-Z])/'   // есть цифра И есть заглавная латинская
```

Бывает и негативный просмотр `(?!X)` — «дальше **нет** X».

### Буквы любого алфавита — `\p{Lu}` и `\p{Ll}`

Нужны и кириллица, и латиница. Писать `[A-ZА-ЯЁ]` можно, но короче готовые классы: `\p{Lu}` — любая заглавная буква, `\p{Ll}` — любая строчная. Работают только с модификатором `u`.

### Обратная ссылка `\1` — «то же самое ещё раз»

`\1` внутри шаблона означает «ровно то, что совпало с первой группой». Поэтому `(.)\1` — любой символ, за которым идёт **он же**: `ss`, `11`, `!!`.

```php
preg_match('/(\w)\1/', 'hello');   // 1 — нашлось "ll"
preg_match('/(\w)\1/', 'world');   // 0
```

Запрет «двух одинаковых подряд» — негативный просмотр: `(?!.*(.)\1)` — «дальше нигде нет символа, повторённого дважды».

### Собранный шаблон

```php
'/^(?=.*\p{Ll})(?=.*\p{Lu})(?=.*\d)(?=.*[!@#%^&*])(?!.*(.)\1)\S{8,}$/u'
```

| Кусок | Требование |
|---|---|
| `(?=.*\p{Ll})` | есть строчная буква |
| `(?=.*\p{Lu})` | есть заглавная буква |
| `(?=.*\d)` | есть цифра |
| `(?=.*[!@#%^&*])` | есть спецсимвол |
| `(?!.*(.)\1)` | нигде нет двух одинаковых символов подряд |
| `\S{8,}` | сама строка: 8 и больше непробельных символов |
| `^`, `$` | от начала до конца |
| `u` | кириллица |

Все просмотры стоят сразу после `^` и проверяют строку целиком, а «съедает» её только `\S{8,}$`.

| Пароль | Результат | Почему |
|---|---|---|
| `Pas5w0rd!` | подходит | |
| `Пар0ль!Ok` | подходит | кириллица тоже считается |
| `Passw0rd!` | нет | две `s` подряд |
| `Short1!` | нет | 7 символов |
| `pas5w0rd!` | нет | нет заглавной |
| `Pas5w0rd` | нет | нет спецсимвола |
| `Pas5 w0rd!` | нет | пробел |

## Задание 6 — разбор логов сервера

> Получите дату и время запуска всех PHP-модулей, не имеющих FCGI, при этом версия PHP должна содержать 8.

```
[2025-11-03 18:52:40] PHP-8.3-FCGI (default): Инициализация модуля
[2025-11-03 18:52:40] PHP-8.4-FCGI (default): Инициализация модуля
[2025-11-03 18:52:41] PHP-8.3 (default): Рабочий процесс модуля запущен
[2025-11-03 18:52:41] PHP-8.4 (default): Рабочий процесс модуля запущен
```

Нужно получить:

```
Модуль PHP-8.3 – 03.11.2025 в 18:52
Модуль PHP-8.4 – 03.11.2025 в 18:52
```

### Шаблон

```php
preg_match_all(
    '/^\[(\d{4})-(\d{2})-(\d{2}) (\d{2}:\d{2}):\d{2}\] (PHP-8\.\d+) \(/mu',
    $log, $m, PREG_SET_ORDER
);
foreach ($m as $x) {
    echo "Модуль $x[5] – $x[3].$x[2].$x[1] в $x[4]<br>";
}
```

| Кусок | Группа | Значит |
|---|---|---|
| `^\[` | | начало строки лога и квадратная скобка (экранирована) |
| `(\d{4})` | 1 | год |
| `-(\d{2})` | 2 | месяц |
| `-(\d{2})` | 3 | день |
| ` (\d{2}:\d{2})` | 4 | часы и минуты |
| `:\d{2}\]` | | секунды — **без** скобок, в ответе они не нужны |
| ` (PHP-8\.\d+)` | 5 | имя модуля: `PHP-8.` и номер |
| ` \(` | | пробел и открывающая скобка |

### Как отсекается FCGI

Отдельной проверки нет. После имени модуля шаблон требует **сразу** пробел и `(`. У строки `PHP-8.3-FCGI (default)` после `PHP-8.3` идёт `-FCGI`, поэтому она не подходит. Версия 7 не пройдёт из-за `PHP-8\.`.

### Модификатор `m`

Лог — много строк в одной переменной. Без `m` якорь `^` означает начало **всего** текста, и нашлась бы максимум первая строка. С `m` `^` — начало **каждой** строки.

### `PREG_SET_ORDER` — результат «по совпадениям»

По умолчанию `preg_match_all` группирует результат **по скобкам**: `$m[1]` — все годы, `$m[2]` — все месяцы. С флагом `PREG_SET_ORDER` — **по совпадениям**: `$m[0]` — всё про первую подходящую строку лога (`[0]` — вся строка, `[1]` — год…), `$m[1]` — про вторую. Так удобнее перебирать `foreach` и собирать строку ответа.

## Задание 7 — дата по группам

> Дана дата в формате 1970-01-01. Замените этот формат на 01.01.1970, используя замену по группам и функцию preg_replace().

```php
echo preg_replace('/(\d{4})-(\d{2})-(\d{2})/', '$3.$2.$1', '1970-01-01');   // 01.01.1970
```

### Ссылки на группы в замене

Группы нумеруются по открывающим скобкам слева направо: 1 — год, 2 — месяц, 3 — день. В строке замены `$1`, `$2`, `$3` — «то, что попало в эту группу». Остаётся переставить их и поставить точки: `$3.$2.$1`.

Если сразу после ссылки идёт цифра, номер берут в фигурные скобки: `${1}0` — «группа 1, потом ноль», а не «группа 10».

Замена работает и внутри текста — все даты сразу:

```php
preg_replace('/(\d{4})-(\d{2})-(\d{2})/', '$3.$2.$1', 'Родился 1970-01-01, сдал 2026-11-13');
// Родился 01.01.1970, сдал 13.11.2026
```

Строку замены пишут в **одинарных** кавычках: в двойных PHP примет `$1` за переменную.

## Задание 8 — IP-адрес

> Проверьте корректность ip-адреса одним регулярным выражением. Четыре октета, каждый от 0 до 255, разделены точками.

### Регулярка не умеет сравнивать числа

Для регулярки `255` — это не число, а три символа. Написать «число от 0 до 255» напрямую нельзя. Поэтому диапазон разбивают на куски, которые можно описать символами:

| Кусок | Числа |
|---|---|
| `25[0-5]` | 250–255 |
| `2[0-4]\d` | 200–249 |
| `1\d\d` | 100–199 |
| `[1-9]?\d` | 0–99 без ведущего нуля |

Октет — любой из кусков: `(?:25[0-5]|2[0-4]\d|1\d\d|[1-9]?\d)`. Порядок важен: длинные варианты стоят первыми.

### Собранный шаблон

```php
'/^(?:(?:25[0-5]|2[0-4]\d|1\d\d|[1-9]?\d)\.){3}(?:25[0-5]|2[0-4]\d|1\d\d|[1-9]?\d)$/'
```

- `(?:октет\.){3}` — октет с точкой, три раза;
- потом четвёртый октет — **без** точки;
- `^` и `$` — ничего лишнего до и после.

| Адрес | Результат |
|---|---|
| `192.168.0.1`, `0.0.0.0`, `255.255.255.255` | подходит |
| `256.1.1.1` | нет — 256 больше 255 |
| `01.2.3.4` | нет — ведущий ноль |
| `1.2.3` | нет — три октета |
| `1.2.3.4.5` | нет — пять октетов |

## Справочник: все функции для регулярок

В заданиях встретились четыре функции. Здесь собраны **все** функции `preg_*` с полным списком аргументов: и те, что были в лабе, и те, что полезно знать.

| Функция | Что делает | Возвращает |
|---|---|---|
| `preg_match` | есть ли совпадение (ищет **первое**) | `1` / `0` / `false` |
| `preg_match_all` | ищет **все** совпадения | число найденных / `false` |
| `preg_replace` | заменяет найденное на строку | новую строку |
| `preg_replace_callback` | заменяет найденное тем, что вернёт функция | новую строку |
| `preg_split` | режет строку по шаблону | массив кусков |
| `preg_quote` | экранирует спецсимволы в строке | строку со `\` |
| `preg_grep` | оставляет элементы массива, подходящие под шаблон | отфильтрованный массив |
| `preg_last_error_msg` | что пошло не так в последнем вызове | текст ошибки |

Обозначения в сигнатурах: `[ ]` — необязательный аргумент, `&` — переменная, в которую функция **сама запишет** результат (заранее создавать её не нужно).

### `preg_match` — есть ли совпадение

```
preg_match(шаблон, строка, [&совпадения], [флаги], [смещение])
```

| Аргумент | Что это |
|---|---|
| `шаблон` | регулярка в одинарных кавычках: `'/\d+/'` |
| `строка` | где ищем |
| `&совпадения` | сюда запишется найденное: `[0]` — всё совпадение, `[1]`, `[2]`… — группы |
| `флаги` | `PREG_OFFSET_CAPTURE` (плюс позиция), `PREG_UNMATCHED_AS_NULL` (ненайденная группа — `null`) |
| `смещение` | с какого **байта** начинать поиск |

**Возвращает:** `1` — нашлось, `0` — не нашлось, `false` — ошибка в самой регулярке (и Warning на странице).

```php
preg_match('/\d+/', 'abc 42 и 7', $m);        // 1,  $m = ["42"] — только первое
preg_match('/\d+/', 'нет цифр');              // 0
preg_match('/(\d+)-(\d+)/', 'код 12-34', $m); // $m = ["12-34", "12", "34"]
preg_match('/\d+/', 'abc 42 и 7', $m, 0, 6);  // $m = ["7"] — поиск начат с 6-го байта
```

**Именованные группы** `(?<имя>...)` — в `$m` попадут и под именем, и под номером:

```php
preg_match('/(?<year>\d{4})-(?<month>\d{2})/', '2025-11', $m);
// $m["year"] = "2025",  $m[1] = "2025"
// $m["month"] = "11",   $m[2] = "11"
```

**В лабе:** задание 1 (поля формы), задание 5 (пароль), задание 8 (IP).

⚠️ Чтобы проверить **всю** строку, а не найти в ней кусок, шаблон должен быть в `^…$`.

### `preg_match_all` — все совпадения

```
preg_match_all(шаблон, строка, [&совпадения], [флаги], [смещение])
```

Аргументы те же, что у `preg_match`, но ищутся **все** совпадения. **Возвращает** их количество (`0`, если ничего нет). Поэтому считать найденное через `count` не обязательно:

```php
$n = preg_match_all('/\d+/', 'abc 42 и 7', $m);   // $n = 2,  $m = [["42", "7"]]
```

Флаги решают, **как разложить** `$m`:

| Флаг                            | Раскладка                                                             |
| ------------------------------- | --------------------------------------------------------------------- |
| ничего или `PREG_PATTERN_ORDER` | **по группам**: `$m[1]` — группа 1 из всех совпадений                 |
| `PREG_SET_ORDER`                | **по совпадениям**: `$m[0]` — первое совпадение со всеми его группами |
| `PREG_OFFSET_CAPTURE`           | каждое значение превращается в пару `[текст, байт]`                   |
| `PREG_UNMATCHED_AS_NULL`        | ненайденная группа — `null` вместо `""` или пропуска                  |

Две строки лога с группами «время» и «модуль»:

```
по умолчанию:     $m[1] = ["18:52", "18:52"]          $m[2] = ["PHP-8.3", "PHP-8.4"]
PREG_SET_ORDER:   $m[0] = [полное, "18:52", "PHP-8.3"] $m[1] = [полное, "18:52", "PHP-8.4"]
```

- Нужен список **одной** группы из всех совпадений — подходит раскладка по умолчанию.
- Каждое совпадение обрабатывается **целиком** в `foreach` — нужен `PREG_SET_ORDER`.

Флаги объединяются через `|`: `PREG_SET_ORDER | PREG_OFFSET_CAPTURE`. Но `PREG_PATTERN_ORDER` и `PREG_SET_ORDER` вместе — `ValueError`, это противоположные раскладки. У `preg_match` эти два флага тоже вызывают `ValueError`: раскладывать одно совпадение нечего.

⚠️ С `PREG_SET_ORDER` выражение `count($m[0])` — это число **групп в первом совпадении**, а не число совпадений. Число совпадений — `count($m)` или то, что вернула функция.

**В лабе:** задание 3 (числа, текст в кавычках), задание 6 (логи).

### `preg_replace` — найти и заменить

```
preg_replace(шаблон, замена, строка, [лимит], [&счётчик])
```

| Аргумент   | Что это                                                       |
| ---------- | ------------------------------------------------------------- |
| `шаблон`   | регулярка или массив регулярок                                |
| `замена`   | на что менять: строка или массив строк                        |
| `строка`   | где менять (можно и массив строк — заменит в каждой)          |
| `лимит`    | сколько замен максимум; `-1` — без ограничений (по умолчанию) |
| `&счётчик` | сюда запишется, сколько замен сделано                         |


**Возвращает новую строку.** Исходная переменная **не меняется**: результат нужно сохранить или сразу вывести.

```php
preg_replace('/\d+/', '#', 'abc 42 и 7');            // "abc # и #"
preg_replace('/\d+/', '#', 'abc 42 и 7', 1);         // "abc # и 7" — только одна замена
preg_replace('/\d+/', '#', 'abc 42 и 7', -1, $cnt);  // $cnt = 2
preg_replace('/\d/', '#', 'abc');                    // "abc" — нечего менять, строка как была
```

Что можно писать **внутри строки замены**:

| Запись | Подставится |
|---|---|
| `$0` | всё совпадение целиком |
| `$1`, `$2`… | группа 1, 2… — для **каждого** совпадения своя |
| `${1}` | группа 1, если сразу за ней в замене идёт цифра |

```php
preg_replace('/(\d+)/', '[$1]', 'abc 42 и 7');   // "abc [42] и [7]"
preg_replace('/\d+/', '<$0>', 'abc 42 и 7');     // "abc <42> и <7>"
preg_replace('/(\d)/', '${1}0', 'a1');           // "a10"
preg_replace('/(\d)/', '$10', 'a1');             // "a" — PHP ищет группу №10, её нет
```

Строку замены пиши в **одинарных** кавычках. В двойных `"$1"` случайно работает: имя переменной PHP не может начинаться с цифры, поэтому PHP её не трогает. А вот `"${1}0"` ломается: PHP считает `${1}` своей переменной, выдаёт Deprecated и Warning «Undefined variable $1», и вместо группы подставляется пустота (`a1` → `a0`).

Какие сочетания шаблона и замены допустимы:

| Шаблон | Замена | Как работает |
|---|---|---|
| строка | строка | обычный случай |
| массив | массив | парами: 1-й шаблон → 1-я замена, 2-й → 2-я (задание 4) |
| массив | строка | все шаблоны заменяются одной строкой: `['/a/', '/b/']` → `'X'` из `"abc"` даёт `"XXc"` |
| строка | массив | ❌ `TypeError` — Fatal error |

⚠️ Пары из массивов выполняются **по очереди**, а не одновременно:

```php
preg_replace(['/кот/', '/пёс/'], ['пёс', 'кот'], 'кот и пёс');
// ожидаешь "пёс и кот", а получается "кот и кот":
// шаг 1: кот → пёс  =  "пёс и пёс"
// шаг 2: пёс → кот  =  "кот и кот"
```

**В лабе:** задание 2 (XSS), задание 3 (пробелы), задание 4 (письмо), задание 7 (дата).

### `preg_replace_callback` — заменить тем, что вернёт функция

```
preg_replace_callback(шаблон, функция, строка, [лимит], [&счётчик], [флаги])
```

Как `preg_replace`, только вместо строки замены — **функция**. Для каждого совпадения она получает массив `$m` (как в `preg_match`) и возвращает, на что его заменить. Нужна, когда замену надо **вычислить**, а подставить `$1` недостаточно.

```php
preg_replace_callback('/\d+/', fn($m) => $m[0] * 2, 'abc 42 и 7');
// "abc 84 и 14" — каждое число удвоено

preg_replace_callback('/(\d{4})-(\d{2})-(\d{2})/', fn($m) => "$m[3].$m[2].$m[1]", '1970-01-01');
// "01.01.1970" — задание 7, только через функцию
```

`fn($m) => ...` — стрелочная функция (лабораторная 8).

### `preg_split` — разрезать строку по шаблону

```
preg_split(шаблон, строка, [лимит], [флаги])
```

| Аргумент | Что это |
|---|---|
| `шаблон` | по чему резать |
| `строка` | что резать |
| `лимит` | максимум кусков; `-1` — без ограничений |
| `флаги` | см. таблицу ниже |

**Возвращает** массив кусков.

```php
preg_split('/[,;]\s*/', 'а, б;в,  г');   // ["а", "б", "в", "г"]
preg_split('/,/', 'а,б,в,г', 2);         // ["а", "б,в,г"] — не больше двух кусков
```

| Флаг | Что делает |
|---|---|
| `PREG_SPLIT_NO_EMPTY` | выкидывает пустые куски |
| `PREG_SPLIT_DELIM_CAPTURE` | оставляет разделители, если они в `( )` |
| `PREG_SPLIT_OFFSET_CAPTURE` | вместе с куском — его позиция |

```php
preg_split('/,/', 'а,,б,');                                     // ["а", "", "б", ""] — пустые куски
preg_split('/,/', 'а,,б,', -1, PREG_SPLIT_NO_EMPTY);            // ["а", "б"]
preg_split('/([,;])/', 'а,б;в', -1, PREG_SPLIT_DELIM_CAPTURE);  // ["а", ",", "б", ";", "в"]
preg_split('//u', 'Привет', -1, PREG_SPLIT_NO_EMPTY);           // ["П", "р", "и", "в", "е", "т"]
```

Чтобы передать флаг, обязательно указать лимит перед ним — обычно `-1`. Последний пример режет строку по буквам: пустой шаблон «совпадает» между каждыми двумя символами. `u` нужен, чтобы резать по буквам, а не по байтам.

**В лабе:** задание 3 (разбить предложение по знакам препинания).

### `preg_quote` — экранировать текст для шаблона

```
preg_quote(строка, [разделитель])
```

Ставит `\` перед всеми спецсимволами регулярок. Нужна, когда в шаблон вставляется **чужой текст** (например, из формы), где могут оказаться `.`, `?`, `(`.

```php
preg_quote('цена 5.99 (руб)?');   // "цена 5\.99 \(руб\)\?"
preg_quote('a/b', '/');           // "a\/b" — второй аргумент: экранировать ещё и разделитель
```

Зачем это нужно:

```php
$word = '5.99';
preg_match("/$word/", '5x99');                          // 1 — точка сработала как «любой символ»
preg_match('/' . preg_quote($word, '/') . '/', '5x99'); // 0 — точка стала обычной точкой
```

### `preg_grep` — отфильтровать массив

```
preg_grep(шаблон, массив, [флаги])
```

Возвращает элементы массива, подходящие под шаблон. **Ключи сохраняются.** Единственный флаг `PREG_GREP_INVERT` — наоборот, вернуть **неподходящие**.

```php
preg_grep('/^\d+$/', ['12', 'abc', '7', 'x1']);                    // [0 => "12", 2 => "7"]
preg_grep('/^\d+$/', ['12', 'abc', '7', 'x1'], PREG_GREP_INVERT);  // [1 => "abc", 3 => "x1"]
```

Это короче, чем `foreach` + `preg_match` + `if`.

### `preg_last_error` и `preg_last_error_msg` — что сломалось

```php
preg_match('/./u', "\xff");   // false — строка не в UTF-8
preg_last_error();            // 4 — константа PREG_BAD_UTF8_ERROR
preg_last_error_msg();        // "Malformed UTF-8 characters, possibly incorrectly encoded"
```

После успешного вызова — `0` и `"No error"`.

⚠️ Если сломан **сам шаблон** (например, незакрытая скобка), PHP сообщает об этом Warning'ом прямо на странице: `Compilation failed: missing closing parenthesis at offset …`. Функция возвращает `false`, а `preg_last_error_msg()` ничего полезного не скажет — смотреть нужно в Warning.

### Частые ошибки

| Ошибка | Что будет | Как надо |
|---|---|---|
| шаблон или замена в двойных кавычках | `\1` превращается в невидимый символ, `${1}` — в переменную PHP | шаблоны и замены — в **одинарных** кавычках |
| результат `preg_replace` не сохранён | на странице старый текст | `$new = preg_replace(...)` или сразу `echo` |
| проверка без `^…$` | проходит строка с мусором вокруг | `'/^…$/'` |
| кириллица без `u` | считаются байты, `{8,}` срабатывает раньше | `'/…/u'` |
| `.` `+` `?` `(` `[` без `\` | работают как спецсимволы | `\.` `\+` `\?` `\(` `\[` или `preg_quote` |
| строка-шаблон и массив-замена | `TypeError` | одна строка замены на один шаблон |

## Ответы на контрольные вопросы

### 1. Что такое метасимволы в регулярных выражениях? Якоря? Квантификаторы? Модификаторы?

- **Метасимволы** — символы с особым смыслом: `. ^ $ * + ? { } [ ] ( ) | \`. Например, `.` — любой символ, `[]` — набор символов, `()` — группа. Чтобы метасимвол означал сам себя, его экранируют: `\.`.
- **Якоря** обозначают не символ, а позицию: `^` — начало строки, `$` — конец, `\b` — граница слова. При проверке поля шаблон оборачивают в `^...$`.
- **Квантификаторы** задают, сколько раз повторяется предыдущий элемент: `?` — 0 или 1, `*` — 0 и больше, `+` — 1 и больше, `{n}`, `{n,}`, `{n,m}`.
- **Модификаторы** пишутся после закрывающего разделителя и меняют поведение всего шаблона: `i` — без учёта регистра, `u` — UTF-8 (кириллица), `s` — точка ловит перевод строки, `m` — `^` и `$` для каждой строки, `x` — пробелы и комментарии в шаблоне.

### 2. Какая бывает квантификация? Приведите примеры.

- **Жадная** (по умолчанию: `*`, `+`, `?`, `{n,m}`) — захватывает как можно больше, потом при необходимости отдаёт по одному символу назад. `/<.+>/` в `<b>x</b>` находит всю строку `<b>x</b>`.
- **Ленивая** (`*?`, `+?`, `??`, `{n,m}?`) — захватывает как можно меньше. `/<.+?>/` находит только `<b>`. Применялась в задании 2 (содержимое `<script>`) и 3 (текст в кавычках).
- **Сверхжадная** (`*+`, `++`, `?+`) — захватывает максимум и **ничего не отдаёт** назад. `/a+a/` в `aaa` находит совпадение, а `/a++a/` — нет: `a++` забрал все `a`, и для последней `a` ничего не осталось.

### 3. Что такое просмотр вперёд и назад?

Проверка того, что стоит после или до текущего места, **без** включения этого в совпадение:

| Запись | Название | Условие |
|---|---|---|
| `X(?=Y)` | позитивный просмотр вперёд | после X идёт Y |
| `X(?!Y)` | негативный просмотр вперёд | после X **не** идёт Y |
| `(?<=Y)X` | позитивный просмотр назад | перед X стоит Y |
| `(?<!Y)X` | негативный просмотр назад | перед X **не** стоит Y |

```php
preg_match_all('/\d+(?=₽)/u', '100₽ 200$ 300₽', $m);   // [100, 300] — знак ₽ в результат не попал
preg_match_all('/(?<=\$)\d+/', '$15 и 20 и $30', $m);  // [15, 30]
```

Главное применение — несколько условий сразу, как в пароле из задания 5. В PHP просмотр назад должен быть фиксированной длины: `(?<=\$+)` — ошибка.

## Что могут спросить на защите

### 1. Зачем `^` и `$` в шаблоне проверки?

Без них `preg_match` ищет совпадение где угодно. `/\d{4}/` «одобрит» и `abc2026xyz`. С `^...$` строка должна целиком совпадать с шаблоном.

### 2. Что вернёт `preg_match`?

`1` — нашлось, `0` — нет, `false` — ошибка в шаблоне. Не `true`/`false`.

### 3. Чем `preg_match` отличается от `preg_match_all`?

Первая ищет одно совпадение и останавливается, вторая — все и возвращает их количество.

### 4. Зачем модификатор `u`?

Русская буква в UTF-8 — 2 байта. Без `u` `.` и `{n}` считают байты, а диапазоны вида `[а-я]` ломаются.

### 5. Почему точку экранируют?

`.` в шаблоне — любой символ. `/\d{2}.\d{2}/` пропустит `01-01` и `01x01`. Нужна именно точка — `\.`.

### 6. Чем `( )` отличается от `(?: )`?

Обе объединяют кусок шаблона. `( )` ещё и запоминает совпадение — его можно достать через `$m[1]` или `$1`. `(?: )` только объединяет.

### 7. Что такое `$1` и `\1`?

Ссылки на первую группу. `$1` — в строке **замены** `preg_replace`. `\1` — внутри **самого шаблона**: «то же, что совпало с группой 1».

### 8. Зачем `.*?` в задании с кавычками, а не `.*`?

`.*` жадный — захватил бы всё от первой открывающей кавычки до последней закрывающей во всём стихотворении. `.*?` останавливается на ближайшей закрывающей.

### 9. Зачем там модификатор `s`?

Одна фраза в кавычках разорвана переводом строки. Без `s` точка не ловит `\n`, и эта фраза не нашлась бы.

### 10. Почему регулярку для IP нельзя написать как `\d{1,3}`?

`\d{1,3}` пропустит `999` и `256`. Регулярка не сравнивает числа, поэтому диапазон 0–255 перечисляют кусками: `25[0-5]|2[0-4]\d|1\d\d|[1-9]?\d`.

### 11. Почему проверку нельзя оставить только в браузере (`pattern`)?

Атрибут убирается в DevTools, а запрос можно отправить вообще без формы. Сервер обязан проверять сам.

### 12. Защищает ли вырезание `<script>` от XSS полностью?

Нет: есть `<img onerror=…>`, `<svg onload=…>` и другие трюки. Надёжно — превратить `<` и `>` в `&lt;` и `&gt;`, то есть `htmlspecialchars`.

## Шпаргалка

| Запись | Что значит | Пример |
|---|---|---|
| `'/.../u'` | шаблон в разделителях + модификаторы | `'/^\d+$/'` |
| `.` | любой символ, кроме `\n` | `a.c` → `abc` |
| `\.`, `\+`, `\(` | экранирование — символ буквально | `\d{2}\.\d{2}` |
| `[abc]` | один символ из набора | `[aeiou]` |
| `[a-z]`, `[0-9]` | диапазон | `[A-Za-z0-9]` |
| `[^0-9]` | любой, кроме | не цифра |
| `[А-ЯЁа-яё]` | русские буквы (с `u`), Ё отдельно | `Пётр` |
| `\d` / `\w` / `\s` | цифра / буква-цифра-`_` / пробельный | `\d{4}` |
| `\D` / `\W` / `\S` | всё, кроме | `\S{8,}` |
| `\p{Lu}` / `\p{Ll}` | заглавная / строчная любого алфавита (`u`) | пароль |
| `?` / `*` / `+` | 0–1 / 0+ / 1+ | `-?\d+` |
| `{n}` / `{n,}` / `{n,m}` | ровно n / n+ / от n до m | `{4,20}` |
| `*?`, `+?` | ленивый | `<.+?>` |
| `++`, `*+` | сверхжадный | `a++` |
| `^` / `$` | начало / конец строки | `^...$` |
| `\b` | граница слова | `\bcat\b` |
| `( )` | группа с запоминанием | `(\d{4})` |
| `(?: )` | группа без запоминания | `(?:com\|ru)` |
| `a\|b` | или | `29\|33\|44` |
| `\1` | повтор группы 1 в шаблоне | `(.)\1` |
| `$1`, `${1}` | группа 1 в замене | `'$3.$2.$1'` |
| `(?= )` / `(?! )` | просмотр вперёд: есть / нет | `(?=.*\d)` |
| `(?<= )` / `(?<! )` | просмотр назад: есть / нет | `(?<=\$)\d+` |
| `i` | без учёта регистра | `/php/i` |
| `u` | UTF-8, кириллица | `/[а-я]/u` |
| `s` | точка ловит `\n` | `/“(.*?)”/su` |
| `m` | `^` `$` для каждой строки | логи |
| `preg_match($re, $s, $m)` | первое совпадение: `1` / `0` | проверка поля |
| `preg_match_all($re, $s, $m)` | все совпадения, их количество | все числа |
| `PREG_SET_ORDER` | результат по совпадениям | логи |
| `preg_replace($re, $repl, $s)` | заменить все совпадения | XSS, дата |
| `preg_replace([..], [..], $s)` | несколько замен за раз | шаблон письма |
| `preg_split($re, $s, -1, PREG_SPLIT_NO_EMPTY)` | разбить по шаблону без пустых частей | знаки препинания |
| `preg_replace_callback($re, fn($m) => …, $s)` | заменить тем, что вернёт функция | удвоить все числа |
| `preg_quote($s, '/')` | экранировать чужой текст для шаблона | `5.99` → `5\.99` |
| `preg_grep($re, $arr)` | оставить подходящие элементы массива | только числа |
| `preg_last_error_msg()` | текст последней ошибки | плохой UTF-8 |
| `htmlspecialchars($s)` | `<` → `&lt;` и т.д. | безопасный вывод |
